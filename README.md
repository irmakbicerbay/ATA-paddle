# ATA Paddle (Phaser.js)

A simple Breakout-style paddle game built with **Phaser 3** (JavaScript).  
Made for **Task 0**: build a simple game in Phaser.js, create a repo, and deploy it.

## Play (Live)
https://irmakbicerbay.github.io/ATA-paddle/

## Repository
https://github.com/irmakbicerbay/ATA-paddle

## Controls
- **A / D** or **← / →**: Move paddle  
- **SPACE**: Launch ball / restart after win/lose  
- **R**: Restart

## ▶️ Run Locally
The game can be run locally using a simple HTTP server or VS Code Live Server.

## 🛠️ Technologies
- Phaser 3
- JavaScript
- HTML5
- GitHub Pages

## 📌 Notes
The game is deployed using GitHub Pages and designed to be simple, clean, and easy to understand.
